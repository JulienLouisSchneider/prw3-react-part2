# Part2

Simple setup guide to run the app in development.

## Requirements
- Node.js (LTS recommended)
- npm

## Install
```bash
npm install
```

## Run Frontend (Dev)
```bash
npm run dev
```

## Run Backend (JSON Server)
```bash
npx json-server --port 3001 db.json
```

Open the app at the URL shown by Vite (usually `http://localhost:5173`).
